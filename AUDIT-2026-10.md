# Security Audit — hermes-free-first-guide — 2026-10-20

## Summary

**Clean bill of health.** Brand-new private Python/docs repo (first commits 2026-10-20, same day as audit) containing a "Hermes free-API handbook", generated PDFs/PNGs, and a stdlib-only setup helper (`skills/hermes-free-first-setup/scripts/setup_free_first.py`, invoked via `scripts/setup_free_first.py`). The helper is defensively written: dry-run by default, refuses `--apply` without `--yes`, never reads/stores/prints API keys, suppresses subprocess stderr/stdout that could contain config values, rejects symlinked configs, backs up before writing with 0600/0700 perms, rolls back on failure, refuses to run against the filesystem or home root, and caps the fetched model catalog at 16 MiB. No credentials, live config, or session data were committed.

Findings: 0 Critical / 0 High / 0 Medium / 2 Low
